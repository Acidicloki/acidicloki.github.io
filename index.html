Discord Bot Backend & Slash Commands Guide

If you want 24/7 background automation, use our companion Python bot with slash commands.

Bot Slash Commands

/bingo card [player_name] [theme]
Generates and renders a custom 5x5 Torn Bingo Card image directly in Discord for the user.
/bingo call [announce: True/False]
Draws the next word from the active pool and broadcasts an embed. (Admin only)
/bingo check [seed] [drawn_words]
Verifies if a specific player's card seed has achieved a winning line or blackout.
/race schedule
Fetches live races from the Torn API and shows countdowns, tracks, and car classes.
/race remind [race_id] [minutes_before]
Schedules an automatic countdown alert before the race starts.

Running the 24/7 Python Bot

# 1. Clone repository & enter folder
git clone <your-repo-url>
cd torn_discord_bingo_suite
# 2. Install dependencies
pip install -r requirements.txt
# 3. Set environment variables in .env
DISCORD_TOKEN=your_bot_token_here
DISCORD_WEBHOOK_URL=your_webhook_url
TORN_API_KEY=your_torn_api_key
# 4. Start the bot
python bot.py
